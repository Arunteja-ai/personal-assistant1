Backend Documentation

The backend is an Express + MongoDB API organized in MVC style. It supports user productivity workflows and a full admin control system, including audit logs, security monitoring, resource inspection, and role-based administration.

Backend Summary

  • Stack: Node.js, Express, MongoDB Atlas, Mongoose
  • Architecture: MVC + services + centralized middleware
  • Security: JWT access tokens, refresh-token rotation, bcrypt hashing, RBAC
  • Admin power: global analytics, user moderation, resource editing, session revocation

Architecture Layout

Client -> Routes -> Middleware (auth, RBAC, rate limit, errors) -> Controllers -> Services (tokens, analytics, security, admin logs) -> Mongoose Models -> MongoDB

Representative Request / Response Examples

Create a Goal

POST /api/goals Authorization: Bearer <access_token> { "title": "Launch internship portfolio", "category": "Career", "priority": "high", "status": "in_progress", "progress": 60, "targetDate": "2026-05-31" }
Response { "message": "Created successfully.", "data": { "_id": "...", "userId": "...", "title": "Launch internship portfolio", "status": "in_progress", "progress": 60 } }

Block a User

PATCH /api/admin/users/:id/status Authorization: Bearer <admin_access_token> { "status": "blocked" }
Result - User account status is updated - All refresh-token sessions for that user are revoked - An admin audit log entry is created

Error Handling and Middleware

  • Centralized `ApiError` class normalizes operational error responses.
  • Mongoose validation and duplicate-key failures are mapped into readable API errors.
  • Rate limiting, Helmet, compression, cookie parsing, and CORS are configured globally.
  • Protected routes enforce JWT validation, blocked-account checks, and role-based access.
Deployment uses environment variables for MongoDB Atlas, JWT secrets, cookie policy, and client origin. No secrets are hardcoded into the source code.

Deployment Notes

The backend includes a Render deployment descriptor and `.env.example`. The production flow is: provision MongoDB Atlas, configure Render environment variables, set the frontend Vercel URL as `CLIENT_URL`, and enable secure cookies for cross-site refresh-token rotation.
